# Package Creation Guide

Quick reference for creating packages in the Ottabase Turborepo monorepo. The authoritative checklist (DB tables,
migrations registry, headless vs rendered entrypoints) is AGENTS.MD → "If adding a new package"; this page covers the
package skeleton only.

## Core Principles

- **Keep packages generic** - Reusable across different apps
- **React dependencies allowed** - Packages can use React/React DOM as peer dependencies
- **No Next.js specifics** - Next.js-specific code belongs in app directories (e.g. `apps/otta-landing`)

## Package Structure

```text
packages/package-name/
├── package.json
├── tsconfig.json
├── vitest.config.ts
├── README.md
├── src/
│   ├── index.ts              # Barrel exports
│   ├── component-name.ts     # Atomic exports
│   ├── components/
│   └── __tests__/
└── dist/                     # Generated by build; .gitignore'd
```

## Package.json Template

```jsonc
{
    "name": "@ottabase/package-name",
    "version": "1.0.0",
    "type": "module", // tsup then emits ESM as .js and CJS as .cjs
    "main": "dist/index.js",
    "types": "dist/index.d.ts",
    "exports": {
        ".": {
            "types": "./dist/index.d.ts",
            "import": "./dist/index.js",
            "require": "./dist/index.cjs",
        },
        "./component-name": {
            "types": "./dist/component-name.d.ts",
            "import": "./dist/component-name.js",
            "require": "./dist/component-name.cjs",
        },
    },
    "sideEffects": false, // Enable tree shaking when possible
    "scripts": {
        // All four are required: turbo silently skips a task a workspace does not declare
        "build": "tsup src/index.ts src/component-name.ts --format cjs,esm --dts --clean",
        "dev": "tsup src/index.ts src/component-name.ts --format cjs,esm --dts --watch",
        "lint": "eslint src", // root eslint.config.mjs; never add a package-local config
        "type-check": "tsc --noEmit",
        "test": "vitest run",
    },
    "dependencies": {
        "@ottabase/config": "workspace:*",
    },
    "peerDependencies": {
        "react": "catalog:",
        "react-dom": "catalog:",
    },
    "devDependencies": {
        "typescript": "catalog:",
        "tsup": "catalog:",
        "vitest": "catalog:",
    },
}
```

## TypeScript Configuration

```json
{
    "extends": "../../tsconfig.json",
    "compilerOptions": {
        "outDir": "dist",
        "jsx": "react-jsx",
        "skipLibCheck": true
    },
    "include": ["src/**/*"],
    "exclude": ["dist", "node_modules"]
}
```

## Atomic Imports (Tree Shaking)

Create individual entry files for better tree shaking:

```typescript
// src/component-name.ts
export { default as ComponentName } from './components/ComponentName';
```

Add to package.json exports and build script:

```json
{
    "exports": {
        "./component-name": {
            "types": "./dist/component-name.d.ts",
            "import": "./dist/component-name.js",
            "require": "./dist/component-name.cjs"
        }
    },
    "scripts": {
        "build": "tsup src/index.ts src/component-name.ts --format cjs,esm --dts --clean"
    }
}
```

Usage:

```typescript
// Atomic import (better tree shaking)
import { ComponentName } from '@ottabase/package-name/component-name';

// Barrel import (convenience)
import { ComponentName } from '@ottabase/package-name';
```

## Tailwind Integration

Consumer apps must include package source in Tailwind config:

```javascript
// tailwind.config.cjs
module.exports = {
    content: ['./app/**/*.{js,ts,jsx,tsx}', '../../packages/package-name/src/**/*.{js,ts,jsx,tsx}'],
};
```

## Dependencies

- **Workspace packages**: `"@ottabase/config": "workspace:*"`
- **Catalog packages**: `"lucide-react": "catalog:"`
- **Peer dependencies**: React/React DOM (avoid Next.js peer deps)

Use `catalog:` for shared dependencies defined in pnpm-workspace.yaml (e.g., TypeScript, tsup). Use `workspace:*` for
internal packages. Declare framework dependencies (e.g., React) as peerDependencies to avoid duplication

## Development Workflow

```bash
pnpm install
pnpm turbo run build --filter=@ottabase/package-name
pnpm --filter @ottabase/package-name dev   # Watch mode
```

## Testing

Every package carries its own Vitest suite in `src/__tests__/` (see [TESTING.md](TESTING.md)):

```bash
pnpm test --filter=@ottabase/package-name
```

Then exercise it in the primary app (`apps/otta-web`):

```typescript
// apps/otta-web/src/pages/test-page.tsx
import { ComponentName } from '@ottabase/package-name/component-name';

<ComponentName prop1="value" />
```

## Key Reminders

- Packages should be **framework-agnostic** as much as possible
- App-specific code goes in the relevant app directory (primary: `apps/otta-web`)
- Use `skipLibCheck: true` in tsconfig
- Declare `lint`, `type-check`, `test` and `build` scripts (exception: `./src`-exported packages omit `build`, see
  AGENTS.MD)
- Include package sources in consumer app Tailwind config
