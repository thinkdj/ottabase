# Drizzle Migrations

This directory contains SQL migration files generated by `drizzle-kit`.

## Drizzle Option 2: Codebase First Approach

This project uses Drizzle's "codebase first" migration approach:

1. **Schema Definition**: Tables are defined in TypeScript (`ottabase/db/schema.ts`)
2. **Migration Generation**: `drizzle-kit generate` creates SQL migration files from schema changes
3. **Migration Application**: `wrangler d1 migrations apply` applies migrations to D1

## Workflow

### Development

```bash
# 1. Make schema changes in ottabase/db/schema.ts
# 2. Generate SQL migrations
pnpm db:generate

# 3. Apply migrations to local D1
pnpm db:migrate

# 4. (Optional) Open Drizzle Studio for database browsing
pnpm db:studio
```

### Production

```bash
# Apply migrations to remote D1 database
pnpm db:migrate:remote
```

## Directory Structure

```
drizzle/migrations/
├── 0000_*.sql        # Initial migration
├── 0001_*.sql        # Schema changes
├── meta/             # Drizzle metadata (auto-generated)
│   ├── _journal.json # Migration tracking
│   └── 0000_snapshot.json
└── README.md         # This file
```

## Commands

| Command | Description |
|---------|-------------|
| `pnpm db:generate` | Generate SQL migrations from schema changes |
| `pnpm db:migrate` | Apply migrations to local D1 |
| `pnpm db:migrate:remote` | Apply migrations to remote D1 (production) |
| `pnpm db:studio` | Open Drizzle Studio for database management |

## Schema Location

- **Core tables**: Defined in `ottabase/db/schema.ts`
- **App-specific tables**: Add new tables to `ottabase/db/schema.ts`

## Notes

- **Never manually edit** generated SQL migration files
- **Commit migrations** to version control
- **Run migrations** after deploying new code
- For schema reference, see the [Drizzle ORM documentation](https://orm.drizzle.team/docs/sql-schema-declaration)
