# Guidelines

- Framework is not live yet. So **NO BACKWARD COMPATIBILITY** and legacy overhead is required.
- Implement the **simplest possible solution** to fix the issue or create a feature. Do not over-engineer.
- Add comments in code wherever necessary.
- DO NOT delete existing comments or code blocks unless they are directly related to the issue being fixed.
- If you're editing a package, only build the package you're working on. Do not build the entire monorepo.
- If you're editing a package, only run tests for that package. Do not run the entire monorepo tests.
- Follow repo nuances and conventions. If unsure, ask for clarification.
- If you encounter any blockers or uncertainties, communicate them immediately. Do not proceed with assumptions.
- Document any assumptions or decisions made during development in the code comments or in the PR description.
